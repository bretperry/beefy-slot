# Security

## Reporting a vulnerability

Report it privately: open <https://github.com/bretperry/beefy-slot/security/advisories/new>.
Do not open a public issue for a vulnerability.

Include what you ran, what you expected, and what happened. A reproduction helps most.

## What to expect

- This is a one-maintainer project. Reports are read as time allows; there is no response-time promise.
- A fix ships as a new patch release of `beefy-slot`. The advisory credits you unless you ask it not to.

## Supported versions

Only the latest release of `beefy-slot` gets fixes.

## Scope

Scope: bugs in this tool's own code. Bugs in your configuration, or in programs it runs for you, are out of scope.
