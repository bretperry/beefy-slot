# Contributing

Outside pull requests are not accepted yet. Merging code from others needs a contributor agreement
first, and none exists. A pull request now will be closed without review. Open an issue instead.

What helps now:

- **Bug reports and questions:** open an issue at <https://github.com/bretperry/beefy-slot/issues>. Say what you ran,
  what you expected, and what happened.
- **Security problems:** do not open an issue. Follow `SECURITY.md`.
- **Ideas:** open an issue first. A good idea may be built by the maintainer.

When a contributor agreement exists, this file will say how to sign it.
